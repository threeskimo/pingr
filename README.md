## pingr
A basic batch file used to continuously ping Google's public DNS (8.8.8.8) to help detect hiccups in internet connectivity. Can now also ping other IP addresses if given as an argument (e.g., pingr.bat 192.168.1.1)

## pingru
A batch file that continuously pings Google's public DNS (8.8.8.8) and plays the default Windows sound when internet connectivity is detected (UP).  Good for detecting the immediate moment connectivity is restored. Can now also ping other IP addresses if given as an argument (e.g., pingru.bat 192.168.1.1)

## pingrd
A batch file that continuously pings Google's public DNS (8.8.8.8) and plays the default Windows sound when internet connectivity is NOT detected (DOWN).  Good for detecting the immediate moment connectivity is lost. Can now also ping other IP addresses if given as an argument (e.g., pingrd.bat 192.168.1.1)
